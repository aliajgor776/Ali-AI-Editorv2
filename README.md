# PixelAI Mini Photo Editor

A small browser-based photo editor made with HTML, CSS and vanilla JavaScript.

## Features
- Upload JPG/PNG/WEBP
- Brightness, contrast, saturation and blur
- Quick filters
- Rotate and flip
- Auto Enhance and Portrait Pop presets
- Download edited image as PNG
- No backend required; editing happens in the browser

## Run
Open `index.html` in a modern browser.

The editor uses the browser FileReader API to load a user-selected image and Canvas 2D APIs to render/filter/export it.
